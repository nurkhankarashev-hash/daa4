Как закончить задание под свой Moodle ID

1. Распакуй ZIP и открой папку patient-zero в VS Code или IntelliJ.
2. Открой терминал именно в папке patient-zero.
3. Выполни команды по очереди:

java tools/MakeVariant.java ТВОЙ_ID data
javac -encoding UTF-8 -d out src/*.java
java -cp out Main
java tools/Check.java
java -cp out Bench

4. Перепиши 9 результатов из консоли в README.md вместо цифр примера tiny.
5. Заполни в README.md Student ID, Name, Group.
6. В вопросе Mission 3 замени пример Border length на свой результат, если он другой.
7. Открой output/outbreak.html в браузере и сделай скриншот всей страницы.
   Замени файл output/outbreak.png своим скриншотом.
8. По желанию повтори Bench на своём ноутбуке и обнови таблицу.
9. Проверь, что все 4 файла в data теперь созданы из твоего ID.
10. Измени объяснения своими словами, прочитай код и подготовься к тесту защиты.
11. Загрузи папку на GitHub. История локальных коммитов уже лежит в папке .git.
   На GitHub нужна публичная репозитория и ветка main.
12. Отправь ссылку на GitHub в Moodle.

Важное: сейчас в ZIP стоят данные примера tiny и его скриншот.
Это НЕ персональные данные. Своего Moodle ID в сообщении не было.
Не отправляй проект без шагов 3-7.

В README уже есть запись об использовании ChatGPT, потому что это
прямое требование задания. Не удаляй её, если действительно использовал ИИ.
